One sentence that could have replaced an entire pointless meeting. No
context, no explanation — just the line that kills the meeting.

## The line

> Nobody in this meeting learned anything, decided anything, or needed to be here — and we'll do it again next Tuesday.

## How it works

`main.ts` is a tiny line-forge: it holds the single sentence, proves it
against the competition gate (UTF-8, 1–200 characters, one non-blank
line), and writes it to `/output/entry.txt` for the judge.

```sh
node main.ts
```

No dependencies, no network, no build step — plain Node 22+ TypeScript.
